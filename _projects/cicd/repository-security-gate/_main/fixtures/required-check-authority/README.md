# Required-check authority fixtures

These are synthetic, credential-free adversarial fixture identifiers for the
protected producer inventory, static terminal verifier, source-only App
publisher, evidence schemas, generated-surface verifier, and ruleset promotion
plan. The executable fixture bodies are created in disposable repositories by
`repo/tests/repository-security-gate-app.test.cjs`; no fixture contacts GitHub
or contains a real App identity, token, key, webhook, repository, or customer
value.

Every negative case must end without a publishable required-check success.

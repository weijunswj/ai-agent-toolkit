# A1-SOIR R1 Control-Plane Kernel

This source-only module contains the accepted A1 safe-observation, detached
evidence, validation, hard-deny, typed-policy, authority-binding and
structural-impact contract for `DL-AGENT-NATIVE-LOOP-MVP-001-A1-SOIR-R1`.

It is default-off and has no published skill, MCP, provider, filesystem,
network, shell, GitHub, or host-adapter surface. Ticket issuance is available
only through the runtime's module-private trusted authority context used by
the focused test harness; production exports cannot self-mint authority.

The runtime is dependency-free and performs no live actions. Invalid or
partial observation evidence can influence only fixed-precedence hard-deny
selection. Ordinary policy, digests, tickets, and authority routing consume
only fully valid detached canonical data.

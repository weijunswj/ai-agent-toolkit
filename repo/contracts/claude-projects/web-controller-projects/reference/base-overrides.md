# Projects overrides of the local Toolkit base

Local Toolkit is the base. The Projects controller follows the global rules, gate rules, governed rules and `CONTROLLER.md` as written. This list is the only place Projects differs from them. Each row names the base clause it changes, why, and the owner's decision behind it (recorded on the Toolkit programme's parent issue). A Projects rule that differs from the base and has no row here is a clash: ask the owner (**Base rule** in `SKILL.md`, and the weekly check in `tasks/base-clash-check.md`).

| Override | Base clause it changes | Why | Owner decision | Ends when |
|---|---|---|---|---|
| Task auto-merge switch is the project line `- Task auto-merge: On` (anything else, or no line, is Off) | Gate rules, Task auto-merge: the app's setup bank answer on this computer is the only switch | A cloud container has no setup answer, so Projects was always Off | 12 Nov 2026: the switch is a project line | Never (Projects has no setup bank) |
| One named merge thread merges in the cloud | Gate rules, Task auto-merge: the controller merges in a session the owner started | Every Projects thread is started by the coordinator | 12 Nov 2026: one merge thread | Never |
| A decision card tap on a merge card counts as the owner's merge OK, for that PR at that head | Gate rules, Task auto-merge: ineligible PRs wait for a typed `merge N` | Projects asks merges by card (record 515) | 12 Nov 2026: cards count now | Card merges become the base rule on every host |
| The hourly programme sweep refreshes programme pages after cloud writes | Governed rules: every session refreshes after its GitHub writes (the checkpoint hook) | Cloud sessions have no signed-in `gh` | 12 Nov 2026: keep the stand-ins for now | The page rebuild ships |
| The footer sweep removes the "Generated by" footer the cloud route adds | Global rules: no attribution footers (the footer hook) | The cloud platform adds the footer itself | 12 Nov 2026: keep the sweep | The cloud route stops adding it |
| The merge hold and the undecided-repository hold are skipped in cloud sessions; the merge thread runs the eligibility check itself | Gate rules and `toolkit-merge-hold.cjs`: the hook refuses a merge with no typed approval | The cloud hold must count card taps, which the card-merge work adds | 12 Nov 2026: the cloud hold follows the card-merge work | The cloud hold follow-up ships |

Stricter Projects rules (for example destructive device steps typed in the local Remote Control thread) are additions, not overrides, and need no row.

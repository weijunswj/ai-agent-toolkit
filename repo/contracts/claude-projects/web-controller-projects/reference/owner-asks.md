# Web Controller for Claude Projects: owner asks

Reference for the `web-controller-projects` skill, opened before the coordinator posts a new ask the owner can act on, and on a fresh coordinator's first turn. The skill's precedence, style and approvals apply; where this file and the skill differ, the skill wins.

## Call-to-action pings
- **Owner steps** include a merge, trying the finished feature, a decision, typing text such as `.`, connecting an account or connector, and an approval or host prompt.
- **New asks get a fresh post.** This is an exception to the running-post edit rule. Put the new ask under **Waiting on you**, following **Post layout** and **Link where the owner acts**; link its originating thread by its exact title and say what to tap or type. Carry every still-open owner item into the fresh post. Combine asks discovered together; a further new ask discovered after that post needs its own notifying post. Routine updates and repeated observations of the same ask follow the normal edit rule.
- **Reconcile after a restart.** On the first successful turn of a fresh coordinator, read project chat and reconcile pending work threads, task reports and the promise list. Ping an actionable ask that never reached project chat under this rule, even if it predates the restart. Read enough of the source and relay to identify the actual step; a later unrelated post does not count. A materially changed action or target is a new ask; rewording or rediscovering the same step is not.
- **Confirm the post.** Read back a successful post before treating the ask as relayed. If posting or notification status is uncertain, inspect chat and the host response before retrying, and report what remains unverified. Never claim the owner was notified merely because text was edited or a tool call was attempted. A reply or reaction does not complete an outstanding native step.
- **Recovery is an owner ask.** Put every confirmed resumable lane needing owner input in one combined **Waiting on you** list through **Call-to-action pings**. Say "Open each listed thread and type anything, such as `.`, to resume it." Link each thread by its title. Typing text resumes conversation; it grants no approval for held work. Complete the sweep before posting where possible; never send one recovery announcement per lane.

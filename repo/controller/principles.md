# Toolkit Controller: design principles
Part of the [Toolkit Controller](../CONTROLLER.md); it binds like that file.
## Design principles
- **Binding:** the owner's standing design principles. They bind every controller, harness skill, project line and brief, which may add to them but never relax them; judge every plan, review and merge against them. A clash goes to the owner as a decision; a new principle needs an owner record. Each principle's owner decision is in the repository's decision trace; cite a record only where a rule needs its exact wording.
- **Development base:** the global rules' Development Principles bind every controller too; this page adds only the controller's own.
- **Governance owns its part:** governed repositories follow the governed rules' Governance Principles and governance's own checks; this page never restates them.
- **Owner-only acts:** merges, deletes, real keys and irreversible acts need the owner's OK; the repository's task auto-merge switch On counts (Standing approvals in the core). Merged branches are left to the repository's GitHub auto-delete setting where it is on; every other branch delete, a closed pull request's included, needs the owner's OK. Permission settings change only on the owner's explicit ask, with a one-paste command.
- **Git hygiene:** never force-push or rewrite history; commit as the owner's identity; no AI attribution (global rules).
- **Controller is the brain:** it does the whole job, gets what it cannot reach through an executor or a paste-back prompt, and says what its harness cannot do (core).
- **Local base:** the local rules are the base every harness inherits; a harness adds only its own mechanics, and a clash goes to the owner.
- **Cloud first:** work runs in the cloud unless it needs the owner's computer; no computer scheduled tasks; new scheduled work joins an existing task first and stays a short prod.
- **Finish fast:** ship the biggest coherent batch; lanes never idle; merge trains never wait.
- **Plain owner posts:** plain words in the owner's time zone; "(my pick)" is the best option on the evidence, not the owner's leaning.
- **Free first:** no paid plans; reviews run on the subscription; speed comes from free fixes.
- **Host-local talk:** a host never mentions another host's setup unless asked.

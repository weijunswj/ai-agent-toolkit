### Changed

- The cloud Programme Sweep now cleans the "Generated by Claude Code" footer from posts the repository owner wrote in the governed repository and its evidence store, after each refresh, so footer cleaning no longer needs the laptop's sweep. It reads the last 26 hours, or further back when a manual run gives `footer_since`, and writes only counts to the run summary. Refused review-body edits warn and wait for a manual clean; any other failed edit fails the step. The evidence store token gains issues and pull requests write for this.
- `toolkit-github-footer-sweep.cjs` takes `--author <login>` to clean one named author's posts, for a sign-in, such as a GitHub App, that is not that person.

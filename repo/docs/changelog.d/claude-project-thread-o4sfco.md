### Setup

- **Clearer Claude Code settings row.** The recommended Claude Code settings question now reads "Add Toolkit's recommended Claude Code settings that are missing?". Each setting is named by what it does and shows whether Toolkit set it, you set it to the same value, you set a different value (which Toolkit leaves alone), or it is not set. The add choice names exactly which settings it would add, the reason lists only the benefits that will actually hold, and the remove choice says it removes only Toolkit's values.

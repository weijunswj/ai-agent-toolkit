### Changed

- **Task pages follow page layout v2:** PATH, then TASK (`## WHY` with `### PROBLEM`, `### FIX` and `### IF WE SKIP`, then `## DONE WHEN` with its `**Not in scope:**` label), then `# PLAN` as a part of its own, then the PR GRAPH, then AGENT CONTEXT, then the hand-written text. The `# More` heading is gone: hand-written text sits under the generated blocks with its own Title Case headings. New pages have no WHAT (the problem and the fix say it); a page that still has one keeps its words as `## WHAT` at the top of TASK. Pages an earlier Toolkit laid out are redrawn once, with a copy saved first, as before.
- **The PR GRAPH names each PR's task:** its columns are PR Task (the PR's title), PR #, Status and Merged SHA. The tracked PR's Status cell carries the task's gate and, while the owner's test is owed, `UAT owed`. The task state keeps each PR's title (an optional `title` on `prs` entries, at most 256 characters), read by refresh passes; a PR whose title is not read yet shows `-`.
- **No STATUS line on task pages:** review, release, the next action and blockers are in the task's handover file. The task status and the exact UAT state stay in one hidden line in the block, so frozen closed pages and the issue-closure guard read them as before, and STATUS lines older pages still carry keep counting for that guard.
- **Heading rule:** a hand-written heading in capitals below the generated blocks (such as `## NOTES`) holds the page with `PAGE_LAYOUT_HELD`, naming the heading, and is never rewritten. Write it in Title Case.

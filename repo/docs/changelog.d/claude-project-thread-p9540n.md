### Changed

- **Task pages follow page layout v2:** PATH, then TASK (`## WHY` with `### PROBLEM`, `### FIX` and `### IF WE SKIP`, then `## DONE WHEN` with its `**Not in scope:**` label), then `# PLAN` as a part of its own, then the PR GRAPH, then AGENT CONTEXT, then the hand-written text. The `# More` heading is gone: hand-written text sits under the generated blocks with its own Title Case headings. New pages have no WHAT (the problem and the fix say it); a page that still has one keeps its words as `## WHAT` at the top of TASK. Pages an earlier Toolkit laid out are redrawn once, with a copy saved first, as before.
- **The PR GRAPH names each PR's task:** its columns are PR Task (the PR's title, cut to 60 characters so long titles cannot fill the page's budget), PR #, Status and Merged SHA. The tracked PR's Status cell carries the task's gate and, while the owner's test is owed, `UAT owed`. With no PR yet the graph reads `None yet` with the gate and any owed UAT (`None yet · G0 ACTIVE`); when the tracked PR is not among the rows shown, one `Task:` line under the graph carries them. The task state keeps each PR's title (an optional `title` on `prs` entries, at most 256 characters), read by refresh passes; a PR whose title is not read yet shows `-`.
- **No STATUS line on task pages:** review, release, the next action and blockers are in the task's handover file, which the task's AGENT CONTEXT line now links first (`Handover: [handover file](…) · Decisions: …`) when the binding names a GitHub store. The task status and the exact UAT state stay in one hidden line in the block, so frozen closed pages and the issue-closure guard read them as before, and STATUS lines older pages still carry keep counting for that guard.
- **Heading rule:** generated headings are in capitals and hand-written ones are in Title Case by convention. Only a hand-written heading below the generated blocks that reuses a generated name in capitals (such as `## PR GRAPH` or `# STATUS`) holds the page with `PAGE_LAYOUT_HELD`, naming the heading; it is never rewritten. Other headings in capitals, such as `# NOTES`, are left as written.
- **Rules:** the governed rules' programme tracking line now says each child's PR GRAPH shows each PR's SHA, gate and owed UAT, and its handover file the release and review.

### Fixed

- **Merge trains never undo main:** `verify` (and so `land`) now refuses a merge train whose tree differs from a fresh build of its current members on main, and `catchup` and `eject` check their own result the same way, leaving the train as it was on a difference. An eject revert keeps removing its content through later merges, so a change that reached main another way (the ejected member landing alone, a pull request built on it, or an identical change from another pull request) could be deleted when a green train landed. The check compares results, so every such route is closed without listing them; a refused train is rebuilt on main.

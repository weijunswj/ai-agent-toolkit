### Added

- **The governance question bank runs without a permission prompt in Claude Code:** Toolkit's governance hook now approves exactly two command lines, so neither a permission prompt nor auto mode holds them: `node "<script>" setup`, which shows the bank, and the bank answer command with the session's live one-use ticket. Each must run alone, with no other argument, nothing a shell expands and no option beyond a description and a timeout. The script is the running Toolkit copy's, or the managed checkout's when that lies outside the session's repository. Any other command, including `refresh`, `--json` or a chained command, still gets the normal permission check, every refusal check runs first, deny and ask permission rules still win, and cloud sessions get no approval. No permission rows change.

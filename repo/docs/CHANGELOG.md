# Toolkit Changelog

## 3.4.0 (rules and records)

- **Two instruction layers.** Generic rules now live in one global block (`repo/contracts/agent-rules/global-rules.md`) that setup installs into `~/.claude/CLAUDE.md` and `~/.codex/AGENTS.md` (and `~/.gemini/GEMINI.md` when enabled), refreshed at session start and checked by the install check. Repositories carry only the Toolkit-governed block (`toolkit-governed-rules.md`), which is also the opt-in. Root `AGENTS.md` dropped from 42.5 KB to under 14 KB, so the global block plus root `AGENTS.md` fit Codex's 32 KiB limit with CRLF.
- **Versioned, hashed markers** on every Toolkit insert (`BEGIN <NAME> v2 toolkit=<version> sha256=<12 hex>`). Refresh writes only between markers, keeps every other byte, restores hand-edited blocks with a backup, and `toolkit-global-rules.cjs --remove` removes the global block cleanly.
- **New global rules:** entry routing (ordinary task, ungoverned repository, governed repository, controller role), repository-wins precedence above a fixed safety floor, merge only after the owner's OK on external effects, tool preference order, model safety flags, fast-forward after merge, parallel builders on disjoint files, and an installed-result check before UAT. The hand-written "Toolkit Controller Bootstrap" content is folded in; setup reports the now-duplicate section and never edits it.
- **New governed rules:** release plan and one PR per lane, finish-fast batching, fast tests, decision traces (with the new read-only `github-program-reconciler` trace audit), short-plus-full SHA links, takeover records, session folders are never custody, a compact repo map, an authorised-context note, and route proof by the launched session's own metadata with effort pinned at launch.
- **Controller and docs:** `repo/CONTROLLER.md` shortened with every rule kept or moved to the governed block, plus the takeover record and host-neutral route proof; `repo/ARCHITECTURE.md` is now a compact repo map checked by a test; `controller-bootstrap` rebound to the current sources; stale contract references fixed in the skill safety matrix and reconciler skill.
- **Helpers:** G0 and G1 helper turn caps raised to 50 and 60.
- **Removed:** the three manual global templates (`AGENTS/CLAUDE/GEMINI.template.md`) and their generator, older marker spellings, the stale "one pending owner question" stack-selection text, and the source-of-truth block in root `AGENTS.md` (still in the README).

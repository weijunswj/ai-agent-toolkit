# GitHub Program Reconciler

Explicit-only skill for deterministic GitHub programme governance, human-v2
source-bound parent/child/PR projections, bounded history conformance, and
truthful PR-review reconciliation. It preserves the legacy N5/v3 and exact E3
compatibility paths as separate explicit surfaces.

Human-v2 uses one authoritative canonical programme state. The parent carrier
embeds the complete audited state; child and PR carriers require complete
external rebinding. Complete-read dispatch, deterministic digest domains,
PublicSurfaceCodec, exact child selection, global and child-local action
machines, and the narrow HISTORY_EXTENDED_PRE_E4 bridge are enforced by the
local runtime.

This skill never owns review-thread mutation, Ready, merge, Web finality,
provider authority, workflows, MCP, E4 execution, Programme Apply, live
migration, or post-number PR binding without separate controller authority.

This skill is directly canonical. Use the local runtime and focused tests when validating it.

# GitHub Program Reconciler

Deterministic managed GitHub programme reconciliation with v5 explicit bounded lanes, exact base-ref/base-SHA candidate binding, operation-class/provenance-bound native-relationship inspection, pre-operation extension and render-integrity proof, separate managed events and durable run receipts, rich fixed-order Parent/Child/PR views, exclusive lifecycle labels, predecessor coverage, safe PR closing associations, and one preview-bound `PREVIEW -> APPLY -> READBACK_VERIFY -> ZERO_DELTA` path for reconciliation and v4 migration.

Implicit discovery performs inspection and mandatory lifecycle preflight only. Mutation requires a trusted verifier and exact preview/candidate/operation binding; caller assertions do not grant authority. Review mutation, Ready, merge, autonomous finality, providers, workflows, and live adapters are not included.

Current runtime: `repo/scripts/toolkit-github-program-reconciler.cjs`.

v5 bootstrap: `.github/ai-agent-toolkit-programme.json`. Generic Web entry: `repo/contracts/github-program-reconciler/web-controller-entry.md`.

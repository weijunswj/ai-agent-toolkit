# GitHub Program Reconciler

Deterministic managed GitHub programme reconciliation with exact base-ref/base-SHA candidate binding, trusted native-relationship inspection, whole-body programme freshness, authoritative event inventory, rich portable Parent/Child/PR views, exclusive lifecycle labels, predecessor coverage, safe PR closing associations, and one preview-bound `PREVIEW -> APPLY -> READBACK_VERIFY -> ZERO_DELTA` path for reconciliation and migration.

Implicit discovery performs inspection and mandatory lifecycle preflight only. Mutation requires a trusted verifier and exact preview/candidate/operation binding; caller assertions do not grant authority. Review mutation, Ready, merge, autonomous finality, providers, workflows, and live adapters are not included.

Current runtime: `repo/scripts/toolkit-github-program-reconciler.cjs`.

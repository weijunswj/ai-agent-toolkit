# GitHub Program Reconciler

Implicitly discoverable skill for programme state on github.com only: private per-child state documents in a private GitHub state store (compare-and-swap, fence and return IDs), one idempotent reconcile pass (`scripts/programme.cjs`) for native parent/sub-issue links, PR heads, required checks at the head and generated state blocks, the separate read-only decision-trace audit (`scripts/decision-trace-audit.cjs`), the read-only decision history the planning step (G0) runs before planning a child (`scripts/decision-history.cjs`, with the comment-tag parser in `scripts/decision-tags.cjs`) and truthful review records. The reconciler, its state documents, managed blocks and sub-issue links require `.github/toolkit-programme.json`; every `programme.cjs` command refuses without it. Toolkit-governed rules and their issue records are not changed by that file. Repositories without the `TOOLKIT-GOVERNED-RULES` block get no governed issue writes, only coding-governance gates, subagents and portable skills; global rules still apply, including PRs after requested edits and task issues when the user asks to add one. Any session may run the preview (dry run) and report it. Only the appointed controller writes programme state: it holds the parent document and runs every writing command itself, including handing out work, returns, user testing, review and completion. A planning, build or review session it assigns (G0, G1 or G2) writes only its own checkpoint journal; helpers never write. It never closes, deletes or merges.

The skill is directly canonical; its document schemas are in `repo/contracts/programme-state/` in the Toolkit repository.

Completed tasks with no PR automatically recover a merged PR from body references, closing links and timeline cross-references in the same repository. The latest merge wins, with the higher PR number breaking an exact timestamp tie. Existing PRs are preserved; retired tasks are excluded and show `-` in the Programme Graph PR column.

Discovery shares a ten-page closed-PR scan, batches twenty issues per link query and permits at most sixty additional discovery and detail requests per pass. Incomplete evidence reports `PR_DISCOVERY_INCOMPLETE` without selecting a PR or resolving an earlier missing-PR finding; a complete search with no match reports `COMPLETED_PR_MISSING`. The normal guarded state writer rechecks eligibility before saving the selected PR. Later passes retry unresolved tasks and recover interrupted projections. See [the attention and reconciliation rules](SKILL.md#attention) for matching, limits and recovery.

# Toolkit Playbooks

The Toolkit's working playbooks, shipped with the plugin so no repository needs its own copy: safety gates, git completion and closing comments, decision traces, privacy-safe checks, generated files, docs governance, local docs, fast tests and sharding, Windows command hygiene, n8n workflows, release readiness, invariant models and model safety flags.

The plugin installs this folder with the other skills; it is not for copying by hand. The playbooks link to each other by relative path.

[SKILL.md](SKILL.md) is the index: read it first, then only the playbooks that match the task. The skill writes nothing and grants no authority; each playbook names its own approval stops.

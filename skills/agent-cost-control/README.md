# Agent Cost Control Skill

Copy the whole [agent-cost-control](./) skill folder when an agent sets up or reviews scheduled tasks, routines, loops, automations, helper agents, spawned threads or workflow steps that call a model.

This README is only an install and identity note. Runtime guidance lives in `SKILL.md`: the small, mid and top ladder with medium effort as the floor, written reasons for every raise, where each host keeps its model and effort settings, and how long-running threads rotate with handoff files. It bundles no scripts.
